# One Million Checkboxes
An attempt to recreate the One Million checkboxes website.   
The real website is located [here](https://onemillioncheckboxes.com/).

I just decided to try to recreate this to learn a little about React, Go, and Valkey/Redis.


# Running the program
```
npm install
npm run dev
```

```
go mod download
go run .
```
